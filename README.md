# STUDIO / AI — Gili's Claude V3

מדריך הקמה מעשי המבוסס על גרסת הצ׳קליסט המקורית (commit `5d29381c70e58e6aa880fd6f1d451c54b345a4e2`) ועל מיפוי סביבת העבודה. גרסה משוכתבת, לא שחזור byte-for-byte. 10 שלבים, 81 משימות, 14 Skills מבוססי הוראות.

## הפעלה
1. חלץ את הארכיון. פתח `index.html` ישירות ב-Edge/Chrome. אין התקנת Node, npm, backend, API או שרת.
2. להעלאה: העתק את *תוכן* התיקייה `GilisClaude-v3` לשורש המאגר הקיים, כולל `skills/`, `templates/`, `data.js`, `app.js`, `style.css`, `README.md`, `index.html`.
3. בדוק `git status`, פתח את האתר מקומית, ואז `git add index.html style.css app.js data.js README.md skills templates`, `git commit -m "Update Gili workspace implementation guide v3"`, `git push`. אם GitHub Pages כבר מוגדר לשורש `main`, אין צורך לשנות הגדרות; אם לא, Settings → Pages → Deploy from a branch → main → / (root) → Save.
4. אל תעלה חומרי לקוחות, גיבויי התקדמות, נתיבי שרת או מפתחות. האתר אינו מתחבר למערכות. אם המאגר/Pages ציבוריים, התוכן גלוי; בדוק מדיניות החברה לפני פרסום. אין קבצי דוגמה אמיתיים.

## תוכן ותחזוקה
- `data.js`: שלבים, מזהי משימות, אחריות, API/אישור, הוראות, מבחני הצלחה, פרומפטים וקישורים. שמור על מזהי המשימות בעת עריכה כדי לא לאבד סימוני V3.
- `app.js`, `style.css`: ממשק, חיפוש, סינון, שמירת התקדמות, גיבוי/שחזור, הדפסה.
- `skills/`: 14 ZIPs, בכל אחד תיקיית Skill ו-SKILL.md עם YAML. אין קוד ריצה, סודות או חיבור. התקנה לפי הממשק הזמין ב-Claude; לא נבדקה בחשבון של גילי.
- `templates/`: תבניות ריקות/דוגמאות פיקטיביות; CSV בקידוד UTF-8 BOM עבור Excel.
- סימונים נשמרים ב-localStorage של הדפדפן. מעבר מ-V1/V2 אינו מייבא סימונים ישנים (התוכן השתנה). אפשר לייצא JSON של סימוני V3 ולייבא באותו מבנה.
- שמות הכפתורים ב-Claude וב-Adobe תלויים בגרסה; קישורים רשמיים למשימות רלוונטיות. Microsoft 365 ארגוני מחייב consent ב-Entra; Claude Pro אינו כולל API. אין מידע מספיק לקבוע API של המערכת הפרטית או להבטיח תמיכה בכונן הרשת, ולכן נדרש פיילוט ואישור IT. לא נכללו סקריפטים Adobe או שרת MCP מוכנים להרצה, משום שגרסאות וממשקים לא ידועים.

## ספריית Skills ב-V3.1
14 ZIP אישיים (הוראות ללא קוד), 6 דוגמאות רשמיות עם קישורים למקור ולמאגר Anthropic, ו-4 יכולות מסמכים מובנות. סדר עדיפויות ליבה/הרחבה. לכל מיומנות יש התקנה, שימוש, פרומפט ובדיקה. לא מעלים את כל המאגר הרשמי בבת אחת. אין צורך ב-API לשימוש רגיל; התקנה בפועל כפופה לאישור ולזמינות בחשבון. מזהי המשימות הקודמים ומפתח localStorage נשמרו.

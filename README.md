# STUDIO / AI — GilisClaude V2.0

סילבוס ויזואלי אישי בעברית. האתר עצמאי ואינו דורש התקנה, שרת או npm.

## פתיחה מקומית
פתחו את `index.html` בדפדפן.

## עדכון GitHub
1. חלצו את קובץ ה-ZIP.
2. שמרו גיבוי של `index.html` הקיים בריפוזיטורי או צרו ענף נפרד.
3. העלו את `index.html` החדש לתיקיית השורש של הריפוזיטורי הקיים (לא את תיקיית העטיפה), והחליפו את הקובץ הקודם.
4. בצעו Commit. אם GitHub Pages כבר מופעל, בדקו את הפריסה ואת האתר.

התקדמות נשמרת מקומית בדפדפן בלבד. אין להעלות מידע ארגוני חסוי. הריפוזיטורי ציבורי; יש לוודא הסכמה לפרסום פרופיל העבודה.

# Studio / AI

אתר סטטי בעברית למעקב אחר הקמת סביבת עבודה עם Claude למעצבת גרפית במשרד פרסום.

## הפעלה מקומית
חלצו את ה-ZIP ופתחו `index.html` ב-Chrome או Edge. אין צורך בשרת, התקנה, API או חשבון. אפשר גם להשתמש בשרת סטטי מקומי.

## העלאה ל-GitHub Pages (רק לאחר אישור)
1. צרו repository חדש והעלו את `index.html` ואת `README.md` לשורש.
2. ב-GitHub: Settings → Pages → Build and deployment → Deploy from a branch.
3. בחרו main ו-/(root), לחצו Save. זמינות Pages תלויה בסוג המאגר ובתוכנית GitHub.
4. לאחר הפריסה, GitHub יציג את כתובת האתר. אין להעלות חומרי לקוחות או סודות למאגר.

## פרטיות ותפקוד
האתר כולל 10 שלבים ו-61 משימות, הוראות נפתחות, חיפוש, סינון, העתקת פרומפטים, הדפסה ומד התקדמות. אין תלות בספריות חיצוניות ואין שליחת נתונים. סימונים נשמרים ב-localStorage בדפדפן ובמקור שבו נפתח האתר; אין סנכרון בין מכשירים, ופתיחה כקובץ מקומי תלויה בתמיכת הדפדפן. קישורים חיצוניים נפתחים רק בלחיצה.

המדריך מבוסס על התוכן שנכתב בשיחה, לא על בדיקה של חשבון Claude או מחשב העבודה בפועל. שמות תפריטים וזמינות תכונות משתנים לפי גרסה, מנוי והרשאות. יש לאשר חיבורים וסקריפטים עם IT. האתר אינו מפעיל או מחבר את Claude בעצמו.
